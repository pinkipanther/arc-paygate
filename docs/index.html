Pay-per-call APIs, priced in cents, settled in one transaction.

PayGate is a paywall contract and an HTTP 402 server for humans and AI agents. On Arc the gas token is USDC, so a plain value transfer is a dollar payment: no approve step, no wrapped token, no second asset for gas.
